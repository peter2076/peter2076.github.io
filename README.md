# 远风归途 · 游戏设计文档 App

《远风归途》(Distant Wind: The Way Home) 是一款原创 12+ 西部心灵冒险开放世界游戏的设计文档交互式 Web 应用。

## 启动方式

直接用浏览器打开 `index.html`，或使用本地服务器：

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 内容结构

- **世界观** — 1899 年美国西部时代背景与多元地貌
- **主角人设** — 伊莱·卡森完整角色设定
- **晨曦旅社** — 流民互助团体与成员介绍
- **主线大纲** — 五章节剧情与双结局分支
- **支线奇遇** — 五类温情支线与代表性案例
- **玩法系统** — 荒野生存、营地社交、便民工具等
- **功能对照表** — 对标开放世界生活类功能的设计对照

## 技术

纯 HTML / CSS / JavaScript 单页应用，无构建依赖，响应式布局，支持移动端。
