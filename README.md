# 远风归途 · 游戏设计文档 App

《远风归途》(Distant Wind: The Way Home) 是一款原创 12+ 西部心灵冒险开放世界游戏的设计文档与试玩 Demo。

## 启动方式

```bash
python3 -m http.server 8080
```

- 设计文档：http://localhost:8080/index.html
- **3D 试玩**：http://localhost:8080/demo3d.html
- 2D 试玩：http://localhost:8080/demo.html

## 项目结构

```
├── index.html      # 游戏设计文档（交互式）
├── demo3d.html     # 3D 开放世界试玩（Three.js）
├── demo.html       # 2D 第一章试玩
├── js/
│   ├── data.js     # 2D 游戏数据
│   └── engine.js   # 2D 引擎
└── README.md
```

## 3D 试玩操作

| 操作 | 功能 |
|------|------|
| WASD | 骑马移动 |
| 鼠标 | 环视 |
| Shift | 疾驰 |
| Space | 跨越 |
| E | 与 NPC / 营地互动 |
| F / G | 加速 / 倒退时间 |
| 1-4 | 切换天气 |
| R | 返回营地 |

## 设计文档功能

- 完整原创游戏设定（主角、晨曦旅社、主线/支线、系统对照表）
- 交互式世界地图（点击区域查看详情）
- 生存状态模拟器（体力/饱腹/温暖/疲惫）
- 章节手风琴、NPC 卡片、支线 Tab 切换

## 试玩 Demo 功能

**第一章：旷野初遇** — 哈登平原

| 操作 | 功能 |
|------|------|
| WASD | 移动 |
| E | 互动 / 对话 |
| 空格 | 篝火休息 |
| M | 骑马 / 下马 |
| J | 任务日志 |
| ESC | 暂停 |

### 可体验内容

- 遇见晨曦旅社，与 6 位 NPC 对话
- 任务：帮修马车（采集橡木轴 → 修理）
- 任务：寻回走失马匹（平原北部）
- 采集草药、帮助迷途旅人
- 昼夜循环、多地貌生态、生存状态管理
- 品格声望系统

## 技术

纯 HTML / CSS / JavaScript（ES Modules），无构建依赖，响应式布局。
