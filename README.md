# 尘途灯火 / Trail of Lamplight

1899 年美国西部背景下的 **12+ 休闲冒险向开放世界** Web App。  
对标写实西部地貌与生活氛围，**剧情与角色全部原创**，并移除武器、战斗、通缉与对抗系统。

## 游玩

- 打开 `index.html`：游戏设定百科（主角、暖篷社、主线、支线、系统对照）
- 打开 `play.html`：浏览器旷野 Demo（骑马、露营、工具互动、暖心事件）

本地预览：

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080/
```

## Demo 操作

| 按键 | 功能 |
|------|------|
| WASD | 策马移动 |
| 鼠标 | 环视（点击锁定） |
| Shift | 疾驰 |
| F | 使用当前工具 |
| H | 照料马匹「芦花」 |
| C | 露营休息 |
| 1–4 | 切换天气 |
| 底部工具条 | 望远镜 / 渔网 / 采药铲 / 砍柴斧 / 画板 / 草药包 |

## 合规定位

- 适龄 **12+**
- 无暴力打斗、无血腥、无武器对抗
- 冲突以沟通、调解、申诉与回避纷争区化解
- 收益来自合法劳作与善意委托

## 技术

- 纯静态站点（适合 GitHub Pages）
- Three.js 程序化地形与日夜天气
- 原创生活方式数值：体力、体温、饱腹、休息、马匹羁绊、品格声望
